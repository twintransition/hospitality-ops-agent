# Late Check-in Request Workflow

## Current Business Problem

Guests arriving late require staff to manually verify reservations, check policies, and communicate instructions.

## AI-Assisted Workflow

```
Guest message
      |
Intent extraction
      |
Reservation lookup
      |
Retrieve late arrival SOP
      |
Decision
      |
Response + task creation
```

## Agent Responsibilities

1. Understand request
2. Identify reservation
3. Retrieve applicable SOP
4. Check operational constraints
5. Produce response
6. Log action

## Human Escalation

Requests involving exceptions, refunds, complaints, or security issues require staff approval.
