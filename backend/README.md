# Backend

FastAPI service for hospitality operations workflows.

Planned modules:

```
backend/
├── app/
│   ├── api/
│   ├── agents/
│   ├── workflows/
│   ├── retrieval/
│   ├── database/
│   └── services/
└── tests/
```

Responsibilities:

- expose operational APIs
- execute agent workflows
- connect database tools
- manage SOP retrieval
- store agent actions
